# CLI Banking Application

This is a command-line banking system developed in Python that allows users to register, log in, create bank accounts, make deposits and withdrawals, transfer funds, and view their balances in a bar chart. This project was created as a final assignment for the Python course at Miami Dade College.

## Features

- Secure user registration and login (with password hashing)
- Create checking or savings accounts
- Deposit and withdraw funds
- Transfer funds between accounts
- Transaction logging (CSV format)
- Visualize account balances using matplotlib and pandas
- Data stored in JSON and CSV files
- Modular and organized project structure

## Installation

Steps to run this project locally:

pip install -r requirements.txt  
python main.py

Make sure you have Python 3 installed before running the app.

## FAQ

Q: Do I need a database to run this?  
A: No. All data is stored locally using JSON and CSV files.

Q: Can I run this without installing matplotlib/pandas?  
A: Yes, but the charting feature will not work without them. Install via pip install -r requirements.txt.

# 💻 CLI Banking Application

A command-line banking system written in **Python** that simulates real-world banking operations.  
This project was developed as a final assignment for the **Intro to Python** course at *Miami Dade College*.

---

## 🚀 Features

- 🔐 Secure user registration and login (with password hashing)
- 🏦 Create savings or checking accounts
- 💸 Deposit, withdraw, and transfer funds
- 🧾 Log all transactions in CSV format
- 📊 Visualize account balances using **matplotlib** and **pandas**
- 📂 Local data storage using JSON and CSV files
- 🧩 Fully modular and clean project structure

## ⚙️ Installation

Make sure you have **Python 3** installed. Then:

```bash
pip install -r requirements.txt
python main.py
```

## ❓ FAQ

**Q: Do I need a database to run this?**  
🅰️ No. All data is stored locally using JSON and CSV files.

**Q: Can I run this without matplotlib/pandas?**  
🅰️ Yes, but the balance chart will not display. Use:

```bash
pip install -r requirements.txt
```
